Interceptor 0.26.6

September 12, 2026
  • Asking any iPhone subcommand for --help now prints help instead of running it.
  • An unsigned or stale iPhone runner now fails the launch at once with the signing reason, and an early xcodebuild exit reports its exit code instead of a two-minute registration timeout.

  • The iOS skill and help now state that the XCTest authorization passcode sheet must be entered on the phone.
