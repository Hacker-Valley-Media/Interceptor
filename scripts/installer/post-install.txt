Interceptor (Browser-Only) is installed.

1. Install the Interceptor extension, either way (both share one extension ID):

   Chrome Web Store (Chrome, Brave, Edge):
       https://chromewebstore.google.com/detail/interceptor/gomcpnagjjlhehnkoobkjgnkbleiooed

   Or the unpacked copy Setup dropped on disk (developer path, same version
   as this CLI):
       %LOCALAPPDATA%\Programs\Interceptor\extension
   Open the extensions page (chrome://extensions, brave://extensions, or
   edge://extensions), turn on Developer mode, click "Load unpacked", and
   select that folder.
2. Open a new terminal so Windows loads the updated user PATH.
3. Run:

       interceptor init --verbose

Optional AI skill packs are bundled but are never linked without your consent:

    interceptor skills adopt

The installer stages the extension files on disk but does not change browser
profiles, enable developer mode, load the extension, start the daemon, or
install anything into a browser without consent. The daemon starts on demand
after a CLI or browser-extension request.

Windows support: Windows 11 24H2 or newer, x64 or ARM64, one active interactive
user per machine. The native macOS commands (interceptor macos *) are not
available in this browser-only Windows package.

Setup, repair, uninstall, logs, and troubleshooting:
https://github.com/Hacker-Valley-Media/Interceptor/blob/main/docs/windows-install.md
