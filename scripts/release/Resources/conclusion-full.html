Interceptor (Full) is installed. Three quick steps left.

1. Choose one browser extension route

Install from the Chrome Web Store

Store install: Open the Interceptor Chrome Web Store listing.

Install as an unpacked extension

Use this developer route when testing the extension files installed by the package:

  1. Open chrome://extensions/ (or brave://extensions/)
  2. Toggle Developer mode on (top right)
  3. Click Load unpacked
  4. Select this folder:
    /Library/Application Support/Interceptor/extension
  5. If Interceptor was already loaded from this folder, click its Reload button instead.

After the extension is connected, interceptor reload also refreshes the running extension service worker.

Keep only one Interceptor extension copy in each browser profile. The package installs the desktop software and unpacked files, but your browser installs or loads the extension only after you choose one of the routes above.

2. Allow Privacy & Security prompts on first macOS command

The first time you run an interceptor macos command, macOS will prompt for Accessibility, Screen Recording, and Apple Events for interceptor-bridge. Allow each one in System Settings → Privacy & Security.

3. Optional: register skill packs with your AI tooling

Interceptor ships skill packs that teach AI agents how to drive the browser, macOS, and iOS surfaces, plus the interceptor-research deep-research methodology skill. One command links the skills you choose into the AI runtimes it detects (Claude Code, Codex, and any ~/.agents/skills consumer) — and keeps them current across updates:

interceptor skills adopt

Check what is linked at any time with interceptor skills status. Prefer to do it by hand? Symlink any skill directly, e.g. for Claude Code:

mkdir -p ~/.claude/skills
ln -sfn "/Library/Application Support/Interceptor/skills/interceptor-browser" ~/.claude/skills/interceptor-browser

The same pattern works for any runtime that reads a skills folder (~/.codex/skills, ~/.agents/skills, ~/.openclaw/skills, ~/.config/opencode/skills).

Try it

Open a terminal and run:

interceptor open "https://example.com"

Or, after granting Privacy & Security:

interceptor macos tree

To uninstall later, run
sudo bash "/Library/Application Support/Interceptor/uninstall.sh"
To downgrade Full → Browser only:
sudo bash "/Library/Application Support/Interceptor/uninstall.sh" --bridge-only
